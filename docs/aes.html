1. خلفية تاريخية ومسابقة NIST (1997-2001)

في أواخر التسعينيات، أصبح كسر خوارزمية DES أمراً ملموساً بسبب قصر مفتاحها (56 بت). أطلق المعهد الوطني للمعايير والتقنية (NIST) مسابقة عالمية مفتوحة لاختيار بديل قوي وسريع يحمل اسم Advanced Encryption Standard (AES).

فازت خوارزمية Rijndael التي صممها العالمان البلجيكيان Joan Daemen و Vincent Rijmen بالمركز الأول بفضل بساطتها الرياضية الأنيقة، ومقاومتها الصلبة للهجمات الخطية والتفاضلية، وكفاءتها العالية على شتى أنواع العتاد البرمجي والصلب.

2. البنية الرياضية وحقول غالوا $GF(2^8)$

على عكس شبكة فيستل (Feistel)، تعتمد AES على شبكة الاستبدال والتبديل (Substitution-Permutation Network - SPN). تتعامل الخوارزمية مع مصفوفة حالة $4 \times 4$ بايت (State Matrix):

مواصفات النسخ الثلاث لـ AES

  • حجم الكتلة: ثابت دائماً عند 128 بت (16 بايت).
  • AES-128: مفتاح 128 بت (16 بايت) وعدد 10 دورات.
  • AES-192: مفتاح 192 بت (24 بايت) وعدد 12 دورة.
  • AES-256: مفتاح 256 بت (32 بايت) وعدد 14 دورة.

جبر حقول غالوا $GF(2^8)$

تتم كافة العمليات الحسابية للبايت داخل الحقل المنتهي $GF(2^8)$ بالاعتماد على كثير الحدود غير القابل للاختزال:

m(x) = x⁸ + x⁴ + x³ + x + 1   (0x11B)

يتم إنشاء صندوق التعويض S-Box بحساب المعكوس الضربي $x^{-1}$ داخل الحقل متبوعاً بتحويل أفيني (Affine Transformation) لضمان أقصى درجة تعقيد لا خطي ومقاومة التحليل التفاضلي.

🔄

3. التحويلات الأربعة في كل دورة تشفير

  • 1. تعويض البايتات (SubBytes):

    استبدال لا خطي لكل بايت في مصفوفة الحالة بقيمته المقابلة من جدول $S\text{-box}$ المولد جبرياً.

  • 2. إزاحة الصفوف (ShiftRows):

    تبديل موضعي بإزاحة صفوف المصفوفة دورياً لليسار: الصف الأول 0، الثاني 1، الثالث 2، والرابع 3 بايتات.

  • 3. خلط الأعمدة (MixColumns):

    ضرب كل عمود بمصفوفة مجهولة المعكوس في $GF(2^8)$ لنشر التغيير في بايت واحد إلى جميع بايتات العمود (Diffusion).

  • 4. إضافة مفتاح الدورة (AddRoundKey):

    إجراء عملية XOR بين مصفوفة الحالة والكلمات المشتقة من جدول المفاتيح الموسع (Key Schedule).

تحليل أسطر الكود اليدوي (Line-by-Line Breakdown)

السطر / المقطع البرمجي (Code Snippet) ماذا يخدم هذا السطر وكيف يعمل؟ (Functionality & Purpose)
def gf_mul(a, b): p = 0 for _ in range(8): if b & 1: p ^= a hi = a & 0x80 a = (a << 1) & 0xff if hi: a ^= 0x1b b >>= 1 return p الضرب في حقل غالوا $GF(2^8)$: تنفيذ خوارزمية الفلاح الروسي لحساب حاصل ضرب عنصرين جبريين داخل الحقل النمطي، مع اختزال القيمة بـ 0x1b عند حدوث فيض في البت الثامن.
def gf_inv(a): if a == 0: return 0 res = 1; base = a; exp = 254 while exp > 0: if exp & 1: res = gf_mul(res, base) base = gf_mul(base, base) exp >>= 1 return res المعكوس الضربي الجبري: حساب $a^{-1} = a^{254} \pmod{m(x)}$ استناداً إلى مبرهنة فيرما الصغرى في الحقول المنتهية، لتوليد صناديق التعويض رياضياً دون جداول جاهزة.
inv = gf_inv(i) s = inv ^ rot(inv,1) ^ rot(inv,2) ^ rot(inv,3) ^ rot(inv,4) ^ 0x63 SBOX[i] = s & 0xff التحويل الأفيني (Affine Transform): خلط بتات المعكوس الضربي بعمليات إزاحة وجمع XOR مع الثابت 0x63 لتوليد صندوق التعويض المانع للهجمات التحليلية.
def shift_rows(s): s[1] = s[1][1:] + s[1][:1] s[2] = s[2][2:] + s[2][:2] s[3] = s[3][3:] + s[3][:3] إزاحة الصفوف دورياً: بعثرة المواضع الخطية للبايتات بنقل الصف الأول خطوة واحدة، والثاني خطوتين، والثالث 3 خطوات لليسار.
def mix_columns(s): s[0][c] = gf_mul(2, a0) ^ gf_mul(3, a1) ^ a2 ^ a3 s[1][c] = a0 ^ gf_mul(2, a1) ^ gf_mul(3, a2) ^ a3 ... خلط الأعمدة في الحقل: ضرب أعمدة مصفوفة الحالة بالمصفوفة الثابتة المعيارية لنشر التأثير المتبادل بين بايتات الكتلة كاملة.
def key_expansion(key_bytes): temp = sub_word(rot_word(temp)) ^ (RCON[i // 4] << 24) w[i] = w[i - 4] ^ temp توسيع المفتاح إلى 44 كلمة: اشتقاق 11 مفتاحاً فرعياً للدورات باستعمال الدوران الدوراني للكلمات وتطبيق S-box وثوابت الدورات $Rcon$.

تحليل أسطر الكود باستخدام المكتبات (aes_libs.py)

السطر / المقطع البرمجي (Code Snippet) ماذا يخدم هذا السطر وكيف يعمل؟ (Functionality & Purpose)
from Crypto.Cipher import AES from Crypto.Util.Padding import pad, unpad استيراد مكتبة PyCryptodome: توفير تنفيذ عالي الكفاءة ومكتوب بلغة C مستفيداً من تعليمات العتاد AES-NI المدمجة في المعالجات الحديثة.
cipher = AES.new(key, AES.MODE_ECB) ct = cipher.encrypt(pad(data, AES.block_size)) إنشاء كائن التشفير وحشو الكتلة: تطبيق حشو PKCS#7 القياسي إلى 16 بايت ثم تشفير الكتلة بنمط ECB التعليمي.
pt = unpad(cipher.decrypt(ciphertext), AES.block_size) فك التشفير وإزالة الحشو: استعادة النص الأصلي والتحقق من صحة بايتات الحشو لمنع هجمات التلاعب (Padding Oracle).
aes/aes_libs.py 
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad
import hashlib

key = hashlib.sha256(b"MasterSecretAESKey2026").digest()[:16]
cipher = AES.new(key, AES.MODE_ECB)

ct = cipher.encrypt(pad(b"Hello AES Security", 16))
print("Encrypted:", ct.hex())

dec = unpad(AES.new(key, AES.MODE_ECB).decrypt(ct), 16)
print("Decrypted:", dec.decode())
