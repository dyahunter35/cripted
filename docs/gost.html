1. تاريخ ونشأة المعيار السوفيتي / الروسي

طُوّرت خوارزمية GOST في الأصل خلال حقبة السبعينيات داخل الاتحاد السوفيتي كمعيار تشفير عسكري حكومي سري عالي الحماية. رُفعت عنها السرية لاحقاً في عام 1989 تحت اسم GOST 28147-89، وفي عام 2015 تم تحديث المعيار وصياغته رسمياً تحت اسم GOST R 34.12-2015 متضمناً نسختين: خوارزمية Kuznyechik (كتلة 128 بت)، وخوارزمية Magma الكلاسيكية (كتلة 64 بت).

الهدف الرئيسي من تصميم GOST كان توفير معيار وطني مستقل يضمن حماية فائقة للمعاملات السيادية والمصرفية ضد إمكانيات أجهزة الاستخبارات الغربية، مع كفاءة برمجية عالية في المعالجات البسيطة.

⚙️

2. الهيكل المعماري والخصائص التقنية

تتميز GOST Magma بمواصفات فريدة تمنحها تفوقاً حاسماً على نظيراتها في تلك الحقبة (مثل DES):

المواصفات الأساسية

  • حجم الكتلة: 64 بت (8 بايت) مقسمة إلى نصفين متساويين ($A_1, A_0$).
  • طول المفتاح: 256 بت (32 بايت)، مما يجعل الهجوم الشامل مستحيلاً حاسوبياً.
  • عدد الدورات: 32 دورة كاملة (ضعف عدد دورات DES).
  • صناديق التعويض: 8 صناديق S-box (كل صندوق يستبدل 4 بت بـ 4 بت).
  • الدوران الحلقي: دوران دوراني يساري بمقدار 11 بتاً في كل دورة.

خوارزمية توزيع المفاتيح (Key Schedule)

يتم تقسيم المفتاح الأصلي (256 بت) إلى 8 كلمات فرعية $K_0, K_1, \dots, K_7$ بحجم 32 بت لكل منها، وتستخدم كالتالي:

  • الدورات 1 إلى 24: تكرار ترتيب الكلمات الثلاث الأولى: $K_0 \dots K_7$ ثلاث مرات متتالية (8 × 3 = 24).
  • الدورات 25 إلى 32: عكس ترتيب الكلمات في الدورات الثماني الأخيرة: $K_7, K_6, \dots, K_0$.
  • فك التشفير: مجرد عكس مسار ترتيب المفاتيح دون أي تعديل في المعمارية.
🔄

3. دالة التحويل غير الخطية $g(k, a)$

في كل دورة من الدورات الـ 32، يتم تطبيق دالة التحويل $g$ على النصف الأيمن $a$ والمفتاح الفرعي $k$ عبر الخطوات التالية:

  • الجمع النمطي Modulo $2^{32}$:

    يتم جمع النصف الأيمن مع المفتاح الفرعي جمعاً حسابياً نمطياً: (a + k) mod 2^32 بدلاً من عملية XOR البسيطة.

  • التعويض عبر الصناديق الثمانية (S-Boxes):

    يتم تقسيم الناتج (32 بت) إلى 8 قيم نيبل (Nibbles) بحجم 4 بت لكل قيمة. تمر كل قيمة عبر صندوق S-Box مخصص لإنتاج 4 بت مقابلة، ما يحقق مستوى عالياً من الارتباك (Confusion).

  • الدوران الحلقي لليسار 11 بت ($\lll 11$):

    يتم تدوير الناتج المجمع ذي الـ 32 بت بمقدار 11 خانة جهة اليسار لتحقيق أقصى درجات الانتشار (Diffusion) السريع عبر البتات.

  • الدمج مع النصف الأيسر:

    يطبق ناتج الدالة عبر بوابة XOR مع النصف الآخر للكتلة، ثم يتم تبديل النصفين استعداداً للدورة التالية.

4. التحليل الأمني ومقارنتها مع المعايير الدولية

💎
قوة الحصانة الرياضية: يوفر طول المفتاح (256 بت) فضاء بحث يبلغ $2^{256}$، وهو رقم فلكي يستحيل تجاوزه عبر الهجوم الشامل (Brute-force) حتى بوجود أقوى الحواسيب الكمومية الحالية. بالإضافة إلى ذلك، فإن عدد الدورات الكبير (32 دورة) مع الدوران غير المتناظر (11 بت) يوفر حماية مطلقة ضد التحليل التفاضلي والخطي.

كود المكتبات الكامل — gost/gost_libs.py 
from gostcrypto.gostcipher import GOST34122015Magma
import hashlib

def gost_encrypt(plaintext, password):
    key = hashlib.sha256(password.encode()).digest()
    cipher = GOST34122015Magma(bytearray(key))
    data = plaintext.encode() if isinstance(plaintext, str) else plaintext
    pad_len = 8 - (len(data) % 8 or 8)
    data = data + bytes([pad_len]) * pad_len
    out = bytearray()
    for i in range(0, len(data), 8):
        out += cipher.encrypt(bytearray(data[i:i + 8]))
    return bytes(out)

def gost_decrypt(ciphertext, password):
    key = hashlib.sha256(password.encode()).digest()
    cipher = GOST34122015Magma(bytearray(key))
    out = bytearray()
    for i in range(0, len(ciphertext), 8):
        out += cipher.decrypt(bytearray(ciphertext[i:i + 8]))
    pad_len = out[-1]
    return bytes(out[:-pad_len])
