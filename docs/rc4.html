1. النشأة وفلسفة التشفير التدفقي

صمم عالم التشفير الشهير Ron Rivest خوارزمية RC4 عام 1987 لصالح شركة RSA Security. ظلت الخوارزمية سراً تجارياً حتى عام 1994 عندما نُشرت تفاصيلها مجهولة المصدر على القائمة البريدية Cypherpunks.

على عكس خوارزميات الكتل (مثل DES و GOST) التي تقسم البيانات إلى مجموعات من 8 أو 16 بايت، فإن التشفير التدفقي يعالج البيانات بايتاً ببايت أو بتاً ببت عبر توليد تيار من البايتات شبه العشوائية (Keystream) ثم دمجه مع النص الأصلي عبر بوابة XOR البسيطة.

⚙️

2. خوارزميتي العمل الأساسيتين: KSA و PRGA

تحتوي الخوارزمية داخلياً على مصفوفة تباديل $S$ بحجم 256 بايت ($0 \dots 255$) ومؤشرين $i, j$:

خوارزمية جدولة المفتاح (KSA)

تهيئة وخلط المصفوفة $S$ بالاعتماد على المفتاح السري:

  1. تهيئة المصفوفة: S[i] = i لكل قيم $i$ من 0 إلى 255.
  2. ضبط المؤشر j = 0.
  3. خلط العناصر عبر 256 تكراراً:
    j = (j + S[i] + Key[i mod key_len]) mod 256
    تبديل swap(S[i], S[j]).

خوارزمية توليد التيار العشوائي (PRGA)

توليد بايت تيار المفتاح لكل بايت من النص المراد تشفيره:

  1. i = (i + 1) mod 256
  2. j = (j + S[i]) mod 256
  3. تبديل swap(S[i], S[j])
  4. استخراج بايت المفتاح: K = S[(S[i] + S[j]) mod 256]
  5. التشفير / فك التشفير: CipherByte = PlainByte ⊕ K
⚠️

3. الثغرات الأمنية وسبب الإيقاف الرسمي

شكلت RC4 لسنوات العمود الفقري لأمن الإنترنت (في أنظمة SSL/TLS وشبكات Wi-Fi WEP)، لكن الدراسات الأكاديمية كشفت انحيازات إحصائية خطيرة (Biases) في البايتات الأولى من تيار المفاتيح:

🚫
أبرز الهجمات المكتشفة:
  • هجوم FMS (Fluhrer, Mantin, Shamir 2001): أدى إلى كسر مفاتيح WEP في دقائق بسبب ضعف دمج ناقل التهيئة (IV) مع المفتاح.
  • انحياز البايت الثاني (Mantin-Shamir Bias): احتمالية ظهور الصفر في البايت الثاني تبلغ ضعف الاحتمالية العادية (1/128 بدلاً من 1/256).
  • حظر المعيار في TLS (RFC 7465 عام 2015): حظرت هيئة معايير الإنترنت IETF استخدام جميع مجموعات تشفير RC4 في بروتوكولات TLS نهائياً.
💻

4. الكود البرمجي في المشروع (Python)

rc4/rc4_manual.py (مثال تشغيل) 
from rc4_manual import rc4_encrypt, rc4_decrypt

password = "StreamPassword2026"
text = "بث مشفر باستخدام RC4 التدفقي"

# تشفير النص
ciphertext = rc4_encrypt(text, password)
print("RC4 Ciphertext (Hex):", ciphertext.hex())

# فك التشفير (نفس العملية الرياضية بسبب تماثل XOR)
recovered = rc4_decrypt(ciphertext, password)
print("Decrypted Plaintext:", recovered.decode("utf-8"))
