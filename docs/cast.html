1. خلفية التصميم ومعيار RFC 2144

صُممت خوارزمية CAST-128 في عام 1996 على يد العالمين Carlisle Adams و Stafford Tavares (وحروف اسمها مشتقة من اسميهما: C. Adams & S. Tavares). نُشرت الخوارزمية كمعيار مفتوح مجاني الاستخدام في وثيقة RFC 2144، واكتسبت شهرة وموثوقية عالمية واسعة عندما اختارها Phil Zimmermann لتكون الخوارزمية الافتراضية في حزمة الخصوصية الشهيرة PGP 5.0 وتلتها GNU Privacy Guard (GPG).

⚙️

2. الخصائص الهندسية والدورات المتناوبة

تعتمد الخوارزمية بنية شبكة فايستل (Feistel Network) مع حجم كتلة ثابت يبلغ 64 بت (8 بايت)، وطول مفتاح متغير يتراوح بين 40 بت و 128 بت (في مشروعنا يتم اشتقاق 128 بت كاملة).

عدد الدورات والمفاتيح الفرعية

  • 12 دورة: للمفاتيح التي لا تتجاوز 80 بت.
  • 16 دورة: للمفاتيح الأكبر من 80 بت (بما فيها مفتاح الـ 128 بت القياسي).
  • مفاتيح الحجب (Masking Subkeys $K_m$): 16 مفتاحاً بحجم 32 بت لكل دورة.
  • مفاتيح الدوران (Rotation Subkeys $K_r$): 16 مفتاحاً بحجم 5 بت لتحديد مقدار الإزاحة الدورانية (0 إلى 31).

الأنماط الثلاثة لدوال الدورات ($f_1, f_2, f_3$)

لمنع الهجمات التناظرية، تتناوب الخوارزمية بين ثلاثة أنواع مختلفة من الدوال:

  1. النوع 1 (Type 1): جمع نمطي مع المفتاح $K_m$ ثم دوران يساري بـ $K_r$، ثم دمج مخرجات الصناديق الأربعة بالعمليات $(S_1 \oplus S_2) - S_3 + S_4$.
  2. النوع 2 (Type 2): خلط بـ XOR مع المفتاح ثم دوران، ودمج الصناديق بالعمليات $(S_1 - S_2) + S_3 \oplus S_4$.
  3. النوع 3 (Type 3): طرح نمطي ثم دوران، ودمج الصناديق بالعمليات $(S_1 + S_2) \oplus S_3 - S_4$.
🛡️

3. القوة الأمنية والمناعة ضد الاختراق

🔒
أمان تام ومقاومة مثبتة: صناديق التعويض الكبيرة (8 صناديق بحجم $8 \times 32$ بت) وتنوع العمليات الحسابية (جمع وطرح ودوران وXOR) يمنحان CAST-128 مناعة كاملة ضد هجمات التحليل الخطي والتفاضلي. وحتى اليوم، لا يوجد أي هجوم رياضي معروف أفضل من تجربة جميع الاحتمالات (Brute-force على $2^{128}$ مفتاح).

كود المكتبات الكامل — cast/cast_libs.py 
from Crypto.Cipher import CAST
import hashlib

def derive_key(password):
    return hashlib.sha256(password.encode()).digest()[:16]

def cast_encrypt(plaintext, password):
    key = derive_key(password)
    data = plaintext.encode() if isinstance(plaintext, str) else plaintext
    cipher = CAST.new(key, CAST.MODE_ECB)
    pad_len = 8 - (len(data) % 8 or 8)
    data = data + bytes([pad_len]) * pad_len
    return cipher.encrypt(data)

def cast_decrypt(ciphertext, password):
    key = derive_key(password)
    cipher = CAST.new(key, CAST.MODE_ECB)
    out = cipher.decrypt(ciphertext)
    pad_len = out[-1]
    return out[:-pad_len]

"""CAST-128 (CAST5) -- manual wrapper interface."""
from cast_libs import cast_encrypt, cast_decrypt, derive_key

# استخدام نفس الدوال المرجعية الموحدة
key = derive_key("PGP_Key_2026")
ct = cast_encrypt("Secret PGP Message", "PGP_Key_2026")
print("Encrypted:", ct.hex())
print("Decrypted:", cast_decrypt(ct, "PGP_Key_2026").decode())
