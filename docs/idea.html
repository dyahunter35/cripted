1. النشأة وفلسفة الخلط الجبري

طوّر العالمان Xuejia Lai و James Massey في المعهد الفدرالي السويسري للتكنولوجيا (ETH Zurich) خوارزمية IDEA عام 1991 كبديل متطور وآمن لخوارزمية DES القديمة، واشتُهرت عالمياً حين تم تضمينها كخوارزمية التشفير الأساسية في بروتوكول PGP الشهير لحماية البريد الإلكتروني.

الركيزة الأساسية في تصميم IDEA هي الاستغناء التام عن صناديق التعويض (S-boxes) وجداول التبديل الثابتة، وتحقيق اللاخطية والتشتت (Confusion & Diffusion) عبر الجمع والتبديل بين ثلاث عمليات جبرية من زمر رياضية مختلفة تماماً.

⚙️

2. العمليات الجبرية الثلاث المتعارضة (Incompatible Groups)

تتم كافة العمليات في IDEA على كلمات بطول 16 بت، وتجمع بين ثلاث زمر رياضية متنافرة جبرياً:

العمليات الرياضية للكتلة (16 بت)

  • عملية XOR المنطقية ($\oplus$): جمع نمطي في الفضاء المتجهي الثنائي $\mathbb{F}_2^{16}$.
  • الجمع النمطي ($\boxplus$): جمع نمطي عادي داخل الزمرة الدائرية $\mathbb{Z}_{2^{16}}$.
  • الضرب النمطي بعدد فيرما ($\odot$): ضرب نمطي قياسي بموجب عدد فيرما الأولي $65537 = 2^{16} + 1$.

لماذا العدد 65537 بالذات؟

العدد $65537$ هو عدد فيرما الأولي الرابع ($F_4 = 2^{2^4} + 1$). وبما أنه عدد أولي، فإن جميع الأعداد غير الصفرية تشكل زمرة ضربية مغلقة $(\mathbb{Z}_{65537})^\times$.

يتم تمثيل الصفر بالقيمة $2^{16} = 65536$ لإنشاء تناظر ثنائي وحيد (Bijection) بين الأعداد من 0 إلى 65535، مما يجعل كل مدخل يملك معكوساً ضربياً فريداً وقوياً ضد التحليل الخطي والتفاضلي.

3. جدول المفاتيح الموسع (52 مفتاحاً فرعياً) والدورات

  • توسيع المفتاح (Key Schedule):

    يتم تقسيم المفتاح الأصلي (128 بت) إلى أول 8 مفاتيح فرعية بطول 16 بت. ثم يتم تدوير المفتاح دورياً لليسار بمقدار 25 بت لاستخراج الـ 8 مفاتيح التالية، ويتكرر التدوير حتى اكتمال 52 مفتاحاً فرعياً ($6 \times 8 = 48$ للدورات الثماني + 4 للتحويل النهائي).

  • خطوات الدورة الواحدة (Lai-Massey Structure):

    تُقسّم كتلة البيانات (64 بت) إلى 4 كلمات ($X_1, X_2, X_3, X_4$) وتُدمج مع المفاتيح عبر الضرب والجمع النمطي، ثم تمر عبر صندوق التحويل MA-structure وتُخلط بواسطة XOR، متبوعة بتبديل $X_2$ و $X_3$.

  • فك التشفير وحساب المعكوسات:

    يستخدم فك التشفير نفس خوارزمية التشفير تماماً، لكن بتسلسل معكوس للمفاتيح الفرعية: حيث يتم استبدال مفاتيح الضرب بمعكوسها الضربي $\pmod{65537}$، ومفاتيح الجمع بمعكوسها الجمعي $\pmod{65536}$.

السطر / المقطع البرمجي (Code Snippet) ماذا يخدم هذا السطر وكيف يعمل؟ (Functionality & Purpose)
def mul_mod(a, b): a = 65536 if a == 0 else a b = 65536 if b == 0 else b r = (a * b) % 65537 return 0 if r == 65536 else r الضرب النمطي في زمرة فيرما $\mathbb{Z}_{65537}^*$: معاملة الصفر على أنه $2^{16} = 65536$ لحساب حاصل الضرب النمطي بموجب 65537، ثم إعادة تمثيل الناتج 65536 كصفر، وهو جوهر أمان IDEA.
def inv_mul(a): if a == 0: return 0 return pow(a, 65535, 65537) المعكوس الضربي بموجب عدد فيرما: حساب $a^{-1} \equiv a^{p-2} \pmod{p}$ باستخدام خوارزمية الرفع الأسي السريعة بموجب مبرهنة فيرما الصغرى لاستخدامه في مفاتيح فك التشفير.
def inv_add(a): return (-a) & 0xffff المعكوس الجمعي بموجب $2^{16}$: حساب $-a \pmod{65536}$ لقفل المسجلات الجمعية أثناء فك التشفير.
key_int = ((key_int << 25) & mask128) | (key_int >> (128 - 25)) التدوير الحلقي بمقدار 25 بت: تدوير المفتاح الأصلي كل 8 كلمات لإنشاء باقي المفاتيح الفرعية الـ 52 بتوزيع إحصائي متجانس.
a = x1 ^ x3 b = x2 ^ x4 c = mul_mod(a, subkeys[k + 4]) d = (b + c) & 0xffff e = mul_mod(d, subkeys[k + 5]) f = (c + e) & 0xffff صندوق التحويل MA (Multiplication-Addition Structure): القلب النابض لدورة Lai-Massey، حيث يتم خلط الفروق بين الكلمات بعمليات ضرب وجمع متعاقبة لنشر التشويش عبر كافة المسجلات.
idea/idea_manual.py (مثال تشغيل كامل) 
from idea_manual import idea_encrypt, idea_decrypt

key = "MasterSecretIDEAKey2026"
text = "تشفير البيانات بواسطة خوارزمية IDEA"

ct = idea_encrypt(text, key)
print("IDEA Ciphertext (hex):", ct.hex())

pt = idea_decrypt(ct, key).decode("utf-8")
print("Decrypted Plaintext:", pt)
