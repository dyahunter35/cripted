1. النشأة والسياق التاريخي

تم تطوير خوارزمية DES في مطلع السبعينيات داخل شركة IBM تحت اسم مشروع Lucifer بقيادة العالم Horst Feistel. في عام 1977، تبناها المعهد الوطني للمعايير والتقنية (NIST/NBS سابقاً) في الولايات المتحدة كمعيار رسمي FIPS PUB 46 لتأمين المعاملات والاتصالات غير المصنفة في الأجهزة الفيدرالية والمؤسسات المالية.

شهدت الخوارزمية نقاشاً علمياً واسعاً إثر تدخل وكالة الأمن القومي الأمريكية (NSA) بتعديل محتويات صناديق التعويض (S-Boxes) وتقليص طول المفتاح من 128 أو 64 بت إلى 56 بت فقط، وهو ما جعلها موضع جدل تاريخي حتى تم فك شيفرتها عملياً في أواخر التسعينيات.

📐

2. المعمارية الهندسية وشبكة فايستل (Feistel Network)

تعمل DES كخوارزمية تشفير كتل متناظر (Symmetric Block Cipher). البيانات تعالج في كتل ثابتة بحجم 64 بت (8 بايتات)، وتمر عبر 16 دورة تكرارية متطابقة. ميزة شبكة فايستل الجوهرية هي أن خوارزمية التشفير وفك التشفير تكونان متطابقتين تقريباً، حيث لا يشترط أن تكون دالة الدورة $F$ قابلة للعكس رياضياً.

  • التبديل الابتدائي (Initial Permutation - IP):

    تتم إعادة ترتيب بتات الكتلة المدخلة الـ 64 وفق جدول تبديل ثابت، دون أي تغيير في قيم البتات، لكسر الارتباطات المباشرة مع النص الأصلي.

  • التقسيم إلى نصفين متساويين:

    يتم شطر الكتلة الناتجة إلى نصف أيسر $L_0$ ونصف أيمن $R_0$، حجم كل منهما 32 بت.

  • الدورات الست عشرة (16 Rounds):

    في كل دورة $i$ من 1 إلى 16، يتم حساب النصفين الجديدين عبر المعادلتين:
    L_i = R_{i-1}
    R_i = L_{i-1} ⊕ F(R_{i-1}, K_i)
    حيث يمثل $K_i$ المفتاح الفرعي المخصص للدورة (بحجم 48 بت)، وعلامة ⊕ تمثل عملية XOR البتية.

  • التبديل النهائي (Final Permutation - FP):

    بعد انتهاء الدورة الـ 16، يتم دمج النصفين بشكل معكوس $(R_{16}, L_{16})$، ثم تطبق مصفوفة التبديل المعاكسة تماماً لـ IP والتي يرمز لها بـ $IP^{-1}$.

⚙️

3. دالة الدورة F وتوزيع المفاتيح (Key Schedule)

تعد الدالة $F$ جوهر القوة الرياضية لخوارزمية DES، وتتكون داخلياً من 4 مراحل متسلسلة:

مراحل دالة الدورة $F(R, K)$

  1. جدول التمدد (Expansion E): توسيع النصف الأيمن من 32 بت إلى 48 بت بتكرار 16 بتاً استراتيجياً.
  2. الخلط بالمفتاح (Key Mixing): جمع ناتج التمدد مع المفتاح الفرعي $K_i$ عبر بوابة XOR (48 بت).
  3. صناديق التعويض (S-Boxes): تقسيم الـ 48 بت إلى 8 مجموعات (كل منها 6 بت)، يمر كل منها بصندوق خاص $S_1 \dots S_8$ ليخرج 4 بت، وهو العنصر اللاخطي الوحيد في الخوارزمية.
  4. التبديل (Permutation P): إعادة ترتيب مخرجات الصناديق الـ 32 بت لضمان انتشار التأثير (Diffusion) في الدورة التالية.

جدول توليد المفاتيح (Key Schedule)

  1. إسقاط بتات التماثل (PC-1): تحويل المفتاح من 64 بت إلى 56 بت (تجاهل البت الثامن من كل بايت).
  2. التقسيم والدوران الأيسر (Circular Shifts): شطر المفتاح إلى نصفين (28 بت لكل منهما)، وإجراء دوران يساري بمقدار 1 أو 2 بت بحسب رقم الدورة.
  3. ضغط التبديل (PC-2): اختيار 48 بت من الـ 56 بت لتكوين المفتاح الفرعي $K_i$ لكل دورة من الـ 16.
🛡️

4. التحليل الأمني ومحطات كسر الخوارزمية

على الرغم من مناعة صناديق التعويض في DES ضد هجمات التحليل التفاضلي (Differential Cryptanalysis) التي اكتشفها العالم إيلي بيهام وأدي شامير، إلا أن نقطة الضعف القاتلة في DES كانت طول مفتاحها القصير: 56 بت فقط.

🚨
أسباب توقف استخدام DES معيارياً: فضاء المفاتيح المتاح هو $2^{56} \approx 7.2 \times 10^{16}$ مفتاح. في عام 1998، صممت مؤسسة الجبهة الإلكترونية (EFF) جهاز Deep Crack الذي استطاع فك تشفير رسالة DES في أقل من 56 ساعة، والآن يمكن كسرها في دقائق باستخدام كروت الشاشة الحديثة (GPUs)، ولذلك استبدلت بمعيار AES وحلت محلها Triple DES مؤقتاً.

def _permute(value, table, n):
    """Permute the n-bit integer `value` according to `table` (1-based positions)."""
    result = 0
    for pos in table:
        bit = (value >> (n - pos)) & 1
        result = (result << 1) | bit
    return result


def _rotl28(value, shift):
    return ((value << shift) | (value >> (28 - shift))) & 0x0FFFFFFF


def key_schedule(key_bytes):
    """Derive the 16 48-bit round subkeys from an 8-byte key."""
    if len(key_bytes) != 8:
        raise ValueError("DES key must be 8 bytes long")
    key64 = int.from_bytes(key_bytes, "big")
    key56 = _permute(key64, PC1, 64)
    left = (key56 >> 28) & 0x0FFFFFFF
    right = key56 & 0x0FFFFFFF
    subkeys = []
    for shift in SHIFTS:
        left = _rotl28(left, shift)
        right = _rotl28(right, shift)
        combined = (left << 28) | right
        subkeys.append(_permute(combined, PC2, 56))
    return subkeys


def _des_block(block64, subkeys):
    block = _permute(block64, IP, 64)
    left = (block >> 32) & 0xFFFFFFFF
    right = block & 0xFFFFFFFF
    for k in subkeys:
        tmp = right
        exp = _permute(right, E, 32)
        x = exp ^ k
        s_out = 0
        for i in range(8):
            chunk = (x >> (42 - 6 * i)) & 0x3F
            row = ((chunk & 0x20) >> 4) | (chunk & 0x01)
            col = (chunk >> 1) & 0x0F
            s_out = (s_out << 4) | SBOXES[i][row][col]
        p_out = _permute(s_out, P, 32)
        right = p_out ^ left
        left = tmp
    cipher = (right << 32) | left
    return _permute(cipher, FP, 64)


def encrypt_block(block8, key_bytes):
    subkeys = key_schedule(key_bytes)
    value = int.from_bytes(block8, "big")
    return _des_block(value, subkeys).to_bytes(8, "big")


def decrypt_block(block8, key_bytes):
    subkeys = key_schedule(key_bytes)[::-1]
    value = int.from_bytes(block8, "big")
    return _des_block(value, subkeys).to_bytes(8, "big")


def _pkcs7_pad(data, block_size=8):
    pad_len = block_size - (len(data) % block_size)
    if pad_len == 0:
        pad_len = block_size
    return data + bytes([pad_len]) * pad_len


def _pkcs7_unpad(data):
    if not data:
        return data
    pad_len = data[-1]
    if pad_len < 1 or pad_len > 8:
        raise ValueError("invalid padding")
    if data[-pad_len:] != bytes([pad_len]) * pad_len:
        raise ValueError("invalid padding")
    return data[:-pad_len]


def encrypt(plaintext, key_bytes):
    """Encrypt bytes with DES-ECB + PKCS#7 padding."""
    data = plaintext if isinstance(plaintext, (bytes, bytearray)) else plaintext.encode()
    data = _pkcs7_pad(bytes(data))
    out = bytearray()
    for i in range(0, len(data), 8):
        out += encrypt_block(data[i:i + 8], key_bytes)
    return bytes(out)


def decrypt(ciphertext, key_bytes):
    """Decrypt bytes with DES-ECB + PKCS#7 padding."""
    if len(ciphertext) % 8 != 0:
        raise ValueError("ciphertext length must be multiple of 8")
    out = bytearray()
    for i in range(0, len(ciphertext), 8):
        out += decrypt_block(ciphertext[i:i + 8], key_bytes)
    return _pkcs7_unpad(bytes(out))


def derive_key(password):
    """Derive an 8-byte DES key from an arbitrary password string."""
    digest = hashlib.sha256(password.encode() if isinstance(password, str) else password).digest()
    return digest[:8]

"""DES + steganography using READY-MADE libraries (pycryptodome + Pillow).

Run with:  python3 des_libs.py demo
Requires:  pip install pycryptodome Pillow
"""

import argparse
import hashlib
import math
import os
import struct
import wave

from Crypto.Cipher import DES
from Crypto.Util.Padding import pad, unpad
from PIL import Image


# ---------------- DES (library) ----------------

def derive_key(password):
    return hashlib.sha256(password.encode()).digest()[:8]


def des_encrypt(plaintext, password):
    key = derive_key(password)
    cipher = DES.new(key, DES.MODE_ECB)
    data = plaintext.encode() if isinstance(plaintext, str) else plaintext
    return cipher.encrypt(pad(data, DES.block_size))


def des_decrypt(ciphertext, password):
    key = derive_key(password)
    cipher = DES.new(key, DES.MODE_ECB)
    return unpad(cipher.decrypt(ciphertext), DES.block_size)


# ---------------- Image stego (Pillow) ----------------

def _bytes_to_bits(data):
    bits = []
    for b in data:
        for i in range(7, -1, -1):
            bits.append((b >> i) & 1)
    return bits


def _bits_to_bytes(bits):
    out = bytearray()
    cur = 0
    n = 0
    for bit in bits:
        cur = (cur << 1) | bit
        n += 1
        if n == 8:
            out.append(cur)
            cur = 0
            n = 0
    return bytes(out)


def image_capacity(path):
    with Image.open(path) as im:
        w, h = im.size
    return (w * h * 3) // 8 - 4


def hide_image(input_path, output_path, payload_bytes):
    with Image.open(input_path) as im:
        im = im.convert("RGB")
        w, h = im.size
        pixels = list(im.get_flattened_data())
    full = len(payload_bytes).to_bytes(4, "big") + payload_bytes
    bits = _bytes_to_bits(full)
    if len(bits) > w * h * 3:
        raise ValueError("payload too large for image")
    idx = 0
    new_pixels = []
    for (r, g, b) in pixels:
        if idx < len(bits):
            r = (r & 0xFE) | bits[idx]; idx += 1
        if idx < len(bits):
            g = (g & 0xFE) | bits[idx]; idx += 1
        if idx < len(bits):
            b = (b & 0xFE) | bits[idx]; idx += 1
        new_pixels.append((r, g, b))
    out = Image.new("RGB", (w, h))
    out.putdata(new_pixels)
    out.save(output_path)
    return len(payload_bytes)


def extract_image(path):
    with Image.open(path) as im:
        im = im.convert("RGB")
        pixels = list(im.get_flattened_data())
    bits = []
    for (r, g, b) in pixels:
        bits.append(r & 1)
        bits.append(g & 1)
        bits.append(b & 1)
    length = int.from_bytes(_bits_to_bytes(bits[:32]), "big")
    if length < 0 or length > image_capacity(path):
        raise ValueError("invalid hidden data")
    return _bits_to_bytes(bits[32:32 + length * 8])


# ---------------- Audio stego (wave) ----------------

def audio_capacity(path):
    with wave.open(path, "rb") as w:
        n = w.getnframes() * w.getnchannels()
    return n // 8 - 4


def hide_audio(input_path, output_path, payload_bytes):
    with wave.open(input_path, "rb") as w:
        params = w.getparams()
        frames = w.readframes(w.getnframes())
    if params.sampwidth != 2:
        raise ValueError("only 16-bit PCM WAV supported")
    samples = list(struct.unpack("<" + "h" * (len(frames) // 2), frames))
    full = len(payload_bytes).to_bytes(4, "big") + payload_bytes
    bits = _bytes_to_bits(full)
    if len(bits) > len(samples):
        raise ValueError("payload too large for audio")
    for i, bit in enumerate(bits):
        samples[i] = (samples[i] & ~1) | bit
    with wave.open(output_path, "wb") as w:
        w.setparams(params)
        w.writeframes(struct.pack("<" + "h" * len(samples), *samples))
    return len(payload_bytes)


def extract_audio(path):
    with wave.open(path, "rb") as w:
        frames = w.readframes(w.getnframes())
    samples = list(struct.unpack("<" + "h" * (len(frames) // 2), frames))
    bits = [s & 1 for s in samples]
    length = int.from_bytes(_bits_to_bytes(bits[:32]), "big")
    if length < 0 or length > audio_capacity(path):
        raise ValueError("invalid hidden data")
    return _bits_to_bytes(bits[32:32 + length * 8])


# ---------------- Demo helpers ----------------

def make_sample_image(path, w=128, h=128):
    im = Image.new("RGB", (w, h))
    px = []
    for y in range(h):
        for x in range(w):
            px.append(((x * 2) % 256, (y * 2) % 256, 100))
    im.putdata(px)
    im.save(path)


def make_sample_audio(path, seconds=2, rate=22050):
    with wave.open(path, "wb") as w:
        w.setnchannels(1)
        w.setsampwidth(2)
        w.setframerate(rate)
        frames = bytearray()
        for i in range(rate * seconds):
            frames += struct.pack("<h", int(10000 * math.sin(2 * math.pi * 440 * i / rate)))
        w.writeframes(frames)


def cmd_demo(args):
    os.makedirs("demo_lib", exist_ok=True)
    img = "demo_lib/sample.png"
    aud = "demo_lib/sample.wav"
    make_sample_image(img)
    make_sample_audio(aud)
    text = "Hello from DES (libs)! سلام"
    pw = args.key
    # image
    hide_image(img, "demo_lib/secret.png", des_encrypt(text, pw))
    ct = extract_image("demo_lib/secret.png")
    print("image recovered:", des_decrypt(ct, pw).decode())
    # audio
    hide_audio(aud, "demo_lib/secret.wav", des_encrypt(text, pw))
    ct = extract_audio("demo_lib/secret.wav")
    print("audio recovered:", des_decrypt(ct, pw).decode())


def main():
    p = argparse.ArgumentParser(description="DES + stego using ready-made libs")
    p.add_argument("--key", default="my-secret-key")
    sub = p.add_subparsers(dest="cmd", required=True)

    ih = sub.add_parser("image-hide")
    ih.add_argument("input"); ih.add_argument("output"); ih.add_argument("text")
    ih.set_defaults(func=lambda a: hide_image(a.input, a.output, des_encrypt(a.text, a.key)) or print("done"))

    ish = sub.add_parser("image-show")
    ish.add_argument("input")
    ish.set_defaults(func=lambda a: print("secret:", des_decrypt(extract_image(a.input), a.key).decode()))

    ah = sub.add_parser("audio-hide")
    ah.add_argument("input"); ah.add_argument("output"); ah.add_argument("text")
    ah.set_defaults(func=lambda a: hide_audio(a.input, a.output, des_encrypt(a.text, a.key)) or print("done"))

    ash = sub.add_parser("audio-show")
    ash.add_argument("input")
    ash.set_defaults(func=lambda a: print("secret:", des_decrypt(extract_audio(a.input), a.key).decode()))

    d = sub.add_parser("demo")
    d.set_defaults(func=cmd_demo)

    args = p.parse_args()
    args.func(args)


if __name__ == "__main__":
    main()
