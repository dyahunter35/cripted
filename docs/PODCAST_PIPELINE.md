# 🎙️ دليل منظومة تفريغ ومزامنة بودكاستات التشفير (Podcast Synchronization Pipeline)

تم بناء هذه المنظومة بالكامل لتكون **جاهزة وتلقائية بنقرة واحدة (Turnkey Automated Pipeline)**. كلما قمت بإنشاء بودكاست جديد (عبر NotebookLM أو Gemini أو أي أداة خارجية) وتريد دمجه في المنصة مع السلسلة الزمنية والترجمة الفورية التفاعلية:

---

## 1. كيف تضيف بودكاست جديد لأي خوارزمية؟
كل ما عليك فعله هو:
1. ضع الملف الصوتي في المجلد:
   ```
   public/audio/{slug}_podcast.m4a
   ```
   *(حيث `{slug}` هو اسم الخوارزمية، مثل: `aes` أو `des` أو `blowfish` أو `rc4` أو `rc6` أو `cast` أو `idea` أو `rc5`)*.

2. اطلب مني ببساطة جملة واحدة:
   > **"حدّث بودكاست aes"** أو **"فرّغ بودكاست blowfish"**

وسأقوم فوراً بتشغيل المنظومة وتحديث الموقع بالكامل!

---

## 2. أو يمكنك تشغيل الأمر يدوياً في أي وقت:
إذا أردت تشغيلها بنفسك من الطرفية (Terminal):

```bash
# لمعالجة خوارزمية واحدة فقط:
python3 scripts/sync_podcast_transcription.py --slug aes

# أو لمعالجة كل ملفات m4a الموجودة دفعة واحدة:
python3 scripts/sync_podcast_transcription.py --all
```

---

## 3. ماذا تفعل المنظومة تلقائياً خلف الكواليس؟
1. **قراءة وتحليل الصوت (Audio Ingestion)**:
   - فحص دقة الصوت وحساب الطول الدقيق بالدقائق والثواني (`Duration & Seconds`).
2. **كشف الفواصل ونقاط الصمت (Voice Activity Detection - VAD)**:
   - تقسيم الصوت تلقائياً عند فترات التوقف الطبيعية للكلام إلى جمل متناسقة.
3. **التفريغ العصبي المتوازي (Parallel Neural Speech-to-Text)**:
   - تفريغ كل مقطع إلى نص عربي فصيح ودقيق مع ربطه بتوقيت البدء والانتهاء بالملي ثانية (`start` و `end`).
4. **تحديد نبرات وأدوار المتحدثين (Speaker Diarization)**:
   - تمييز تبادل أطراف الحديث بين المحاور الأول والمحاورة.
5. **تحديث ملف البيانات (JSON Update)**:
   - حفظ السلسلة الزمنية بالكامل في `src/content/podcasts.json`.
6. **العرض التفاعلي في الواجهة (Interactive UI)**:
   - تشغيل شريط الترجمة الحية المتزامنة (`Live Subtitles`).
   - إمكانية القفز الفوري لأي دقيقة وثانية عند النقر على أي جملة (`Click-to-Seek`).
   - التتبع والتحريك التلقائي بين السطور أثناء الاستماع (`Auto-scroll`).
